
Overview and Motivation
----------------------
The Deepfake Detection Website project provides an end-to-end platform for detecting deepfakes in images and videos. With the increasing prevalence of synthetic media generated by GANs and other AI techniques, distinguishing authentic content from manipulated media is a growing challenge. This project aims to address this issue by combining a modern machine learning backend (FastAPI, PyTorch, MongoDB) with a user-friendly React frontend, enabling seamless media uploads, inference, and result visualization. The modular, local-first design makes it accessible for researchers, developers, and educators to experiment with and improve deepfake detection methods.

Objective
---------
The primary objective of this project is to develop a robust, extensible, and easy-to-use system for detecting deepfakes in both images and videos. The system should:
- Enable users to upload media and receive deepfake detection results efficiently
- Support scalable background processing for large or asynchronous tasks
- Allow easy integration and replacement of detection models
- Facilitate experimentation and research in the field of synthetic media detection
- Promote awareness and provide practical tools to help combat misinformation and malicious content online

Backend (FastAPI + Celery + MongoDB)
====================================

Run
---
1) Create venv and install requirements:
   - `python -m venv .venv` (or `python -m venv venv`)
   - Windows PowerShell: `.\.venv\Scripts\Activate.ps1` (or `.\venv\Scripts\Activate.ps1`)
   - `pip install -r requirements.txt`

   **Note**: Face detection dependencies (mtcnn, facenet-pytorch) are included in requirements.txt.
   If you encounter import errors, run the setup script:
   - PowerShell: `.\setup_face_detection.ps1`
   - CMD: `setup_face_detection.bat`

2) Ensure MongoDB and Redis are running locally.

3) Start API:
   - `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`

4) Start Celery worker:
   - `celery -A app.workers.tasks.celery_app worker --loglevel=INFO`

Environment
-----------
Set via `.env` or system environment variables. See `.env.example` at repo root for common values.

Key Paths
---------
- Uploads: `data/uploads`
- Frames: `data/frames/{job_id}`
- Results: `data/results`

Notes
-----
- The model in `app/models/detector.py` is a scaffold. Replace with your trained model later.
- Video pipeline extracts frames via OpenCV and aggregates per-frame scores.
- **Face Detection**: Enabled by default. Automatically detects and extracts faces before inference.
  See `FACE_DETECTION_GUIDE.md` for configuration and usage details.
